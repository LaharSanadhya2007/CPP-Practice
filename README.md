# C++ Inheritance Practice

This folder contains my C++ programs based on different types of inheritance in Object-Oriented Programming (OOPS).

**Course:** B.Tech 2nd Year – 3rd Semester  
**Language:** C++

## Topics Covered

### 1. Single Level Inheritance
- One base class and one derived class.
- Employee Salary Calculation.
- Addition of Two Numbers.

### 2. Multilevel Inheritance
- Inheritance across multiple levels.
- Student Result Management.
- Addition of Numbers.

### 3. Multiple Inheritance
- One derived class inheriting from multiple base classes.
- Student Examination and Sports Result.
- Addition of Two Numbers.

### 4. Hierarchical Inheritance
- Multiple derived classes inheriting from one base class.
- Vehicle Management System.
- Addition of Two Numbers.

### 5. Hybrid Inheritance
- Combination of multiple inheritance types.
- Diamond Problem.
- Virtual Base Classes.
- Student Academic and Sports Result System.

## Concepts Practiced
- Base and Derived Classes
- Public Inheritance
- Protected Access Specifier
- Code Reusability
- Virtual Inheritance
- Diamond Problem
- Ambiguity Resolution

## Tools & Technologies
- C++
- Visual Studio Code
- GCC Compiler

## Objective

To understand and implement different types of inheritance in C++ through practical programming questions and strengthen my OOPS concepts for university examinations.
